# 🔬 Calculadora Científica em Python

## 📖 Descrição do Projeto

Este projeto é uma Calculadora Científica desenvolvida em Python utilizando apenas terminal/console.

O sistema foi criado com o objetivo de praticar lógica de programação, tratamento de erros, operações matemáticas e utilização da biblioteca `math` do Python.

A calculadora realiza desde operações matemáticas básicas até funções científicas avançadas, funcionando de forma simples e interativa diretamente no terminal.

---

# 🎯 Objetivo do Sistema

O principal objetivo deste projeto é:

- praticar programação em Python;
- desenvolver raciocínio lógico;
- aprender estruturas condicionais;
- utilizar loops de repetição;
- trabalhar com validação de dados;
- tratar erros utilizando `try/except`;
- aplicar funções matemáticas da biblioteca `math`;
- criar um sistema funcional e organizado.

# 🛡️ Validações Implementadas

O sistema possui diversas proteções contra erros para evitar falhas durante o uso.

Exemplos:
- impede divisão por zero;
- impede raiz quadrada negativa;
- impede logaritmo de números inválidos;

- trata entradas incorretas do usuário;
- impede operações matemáticas inválidas.

# 🚀 Como Executar o Projeto

## ✅ Pré-requisitos

Antes de começar, você precisa ter instalado:

- Python 3

Para verificar se o Python está instalado, abra o terminal e digite:

```bash
python --version
```

ou

```bash
python3 --version
```

---

# 💻 Passo a Passo para Executar

## 1. Baixe o arquivo do projeto

Salve o arquivo:

```bash
calculadora.py
```

em uma pasta no computador.

---

## 2. Abra a pasta do projeto

Abra a pasta onde o arquivo foi salvo.

---

## 3. Abra o terminal

### Windows
Abra:
- Prompt de Comando
ou
- PowerShell

### Linux
Abra o Terminal.

### Mac
Abra o Terminal.

---

## 4. Execute o código

Digite:

```bash
python calculadora.py
```

Caso não funcione, tente:

```bash
python3 calculadora.py
```
